# Header

![left side of LogicEasy header](/screenshots/header/left.png)

The header provides utility tools for the whole application.

- [**Project**](./project.md): <br>
    Always usable: allows you to **create**, **open**, **import**, **save** and **close** projects. 

    ![header project dropdown](/screenshots/header/project/full.png)


- [**View**](./view.md): <br>
    Only usable when a project is open: allows you to open different project type specific **views**/**panels**.

    ![header view dropdown](/screenshots/header/view/cc.png)


- [**Export**](./export.md): <br>
    Only usable when a project is open: allows you to **export** parts of your project into different formats like **VHDL**, **LogicCircuits**, **LaTeX** or **Images**.

    ![header export dropdown](/screenshots/header/export/image.png)


- **Help**: <br>
    Always usable: provides quick access to this **documentation**, and an about page.     

    ![header help dropdown](/screenshots/header/help.png)


---

The right side of the header shows the opened project. It can be closed by clicking on the cross.

![right side of LogicEasy header](/screenshots/header/right.png)
