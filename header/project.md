# Project Dropdown

The project dropdown is always available, and allows you to manage your projects.

![project dropdown](/screenshots/header/project/full.png)


You can do the following: 

- **New**: <br>
    This allows you to create a new project. You can choose the project type, and the panel/view layout, exactly like on the LogicEasy landing page.

    ![new project dropdown expanded ](/screenshots/header/project/new_expanded.png)

- **Recents**: <br>
    This allows you to open the last 5 opened projects. It shows the project name and when it was last opened.

    ![recent projects dropdown expanded ](/screenshots/header/project/recents_expanded.png)
 
- **Open**: <br>
    This allows you to open a project's *.le file which is saved on your computer. This can also be done using the keyboard shortcut `ctrl` + `O`  

- **Save**: <br>
    This allows you to save a project's *.le file to your computer. This file can be imported back into LogicEasy later. This can also be done using the keyboard shortcut `ctrl` + `S`  

- **Close**: <br>
    This allows you to close a project and get back to the landing page.
