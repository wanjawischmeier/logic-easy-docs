# Views/Panels

Each project type allows different Views/Panels, which may not be directly opened after project creation.
In order to access these Views/Panels, you can click on "Views" in the header. 

For Combinatorial Circuit projects the following views are available: 

![view popup with view list](/screenshots/header/view/cc.png)

- Truth Table: full truth table
- Minimization: 
    - Karnaugh-Veitch: KV-Diagram and formula for each output variable
    - Quine-McCluskey: grouping and prime-implicant-table
- LogicCircuits: read-only LogicCircuits visualization

---

For State Machine projects the following views are available: 

![view popup with view list](/screenshots/header/view/st.png)

- State Table: state-encoding and transition-table
- FSM Editor: visual state machine editor
- LogicCircuits: read-only LogicCircuits visualization
